# PKE Meter 2.0
Really detects your props using UHF RFID tags like the ones stores use for inventory control.
Builds on an older version that used simpler RFID fare card tags. UHF is more expensive, but
it gives you a much greater range of detection. The fare cards required the user to almost 
physically touch the "ghost". The UHF reader gives you up to several feet depending on 
the electromagnetic noise in the area. The big improvements in version 2.0 are:

- Full color, large TFT display
- Animations
- More room for textual descriptions of each ghost
- Longer range for detection
